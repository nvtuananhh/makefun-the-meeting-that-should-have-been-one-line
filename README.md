## What it does

`main.py` (Python 3, standard library only, no network) writes
one sentence to `/output/entry.txt` — the single sentence
that could have replaced an entire pointless meeting:

> We're doing it exactly the way Sarah suggested in March, and this meeting was the only thing still blocking it.

The line is 111 characters long. One sentence, decided in
the room and done: do it the way Sarah suggested in March.
The sting lands on the last words — the meeting itself was
the only thing still blocking it. After this line, no one
could justify holding the meeting at all, and anyone who
has sat through a useless one knows exactly how it goes.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (111 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
